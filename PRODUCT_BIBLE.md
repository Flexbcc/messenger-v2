# Назначение документа

Данный документ является полной продуктовой спецификацией мессенджера.

Он описывает каждый экран, пользовательский сценарий, настройки, элементы интерфейса и поведение приложения.

Этот документ является главным источником информации для разработки Flutter-клиента, backend, UX/UI и документации.

Архитектурные решения описываются в отдельных документах. Здесь описывается исключительно продукт и пользовательский опыт.

---

# Принципы продукта

- Минималистичный интерфейс в стиле iOS.
- Бело-чёрная цветовая схема с минимальным количеством акцентных цветов.
- Максимально простой пользовательский опыт.
- Любая функция должна быть понятна без обучения.
- Privacy First.
- Offline First.
- Все важные действия должны быть доступны не более чем за 2–3 нажатия.
- Интерфейс должен выглядеть спокойно, современно и дорого.

# Экран 001. Splash Screen

## Назначение

Самый первый экран приложения. Показывается сразу после запуска.

## Как сюда попасть

- Первый запуск приложения.
- Каждый последующий запуск.
- После полного закрытия приложения.

## Что пользователь видит

- Логотип приложения.
- Название приложения.
- Индикатор загрузки.
- Номер версии (мелким текстом внизу).

## Что происходит

Приложение автоматически:

- загружает локальные данные;
- проверяет наличие аккаунта;
- проверяет наличие PIN-кода;
- проверяет требуется ли обновление;
- восстанавливает последнюю сессию.

## Возможные переходы

- Welcome Screen — если пользователь новый.
- Unlock Screen — если аккаунт существует.
- Home Screen — если PIN отключён.
- Update Screen — если требуется обязательное обновление.
- Error Screen — если возникла критическая ошибка.

## Особенности

Пользователь не взаимодействует с этим экраном.

# Экран 002. Welcome Screen

## Назначение

Первый экран нового пользователя.

## Как сюда попасть

После Splash Screen, если пользователь ещё не зарегистрирован.

## Что пользователь видит

- Логотип приложения.
- Название приложения.
- Краткое описание возможностей.
- Кнопку «Войти».
- Кнопку «Создать аккаунт».
- Кнопку выбора языка.
- Кнопку выбора темы оформления.
- Ссылки на политику конфиденциальности и условия использования.

## Что пользователь может сделать

- Войти в существующий аккаунт.
- Зарегистрировать новый аккаунт.
- Изменить язык интерфейса.
- Изменить тему оформления.
- Ознакомиться с документами.

## Переходы

- Login Screen.
- Registration Screen.
- Language Screen.
- Theme Screen.

## Особенности

Это максимально простой экран без рекламы, новостей и лишних элементов.

# Экран 003. Login Screen

## Назначение

Авторизация существующего пользователя.

## Как сюда попасть

Из Welcome Screen.

## Что пользователь видит

Поля:

- Email / Телефон / Username.
- Пароль.

Кнопки:

- Войти.
- Забыли пароль.
- Войти по QR.
- Войти через Apple.
- Войти через Google.
- Показать пароль.

## Что пользователь может сделать

- Выполнить вход.
- Восстановить пароль.
- Использовать альтернативные способы входа.

## Переходы

- Unlock Screen.
- Home Screen.
- Password Recovery Screen.
- QR Login Screen.

## Особенности

При успешном входе приложение предлагает настроить PIN и биометрию, если они ещё не настроены.

---

# Экран 004. Registration Screen

## Назначение

Создание нового аккаунта.

## Как сюда попасть

Из Welcome Screen.

## Что пользователь видит

Поля:

- Имя.
- Username.
- Email.
- Телефон (необязательно).
- Пароль.
- Повтор пароля.

Переключатели:

- Получать уведомления.
- Настроить PIN после регистрации.

Кнопки:

- Создать аккаунт.
- Назад.

## Что пользователь может сделать

- Зарегистрировать новый аккаунт.
- Вернуться на предыдущий экран.

## Переходы

- Verification Screen.
- Welcome Screen.

## Особенности

Регистрация должна занимать не более одной минуты.

---

# Экран 005. Verification Screen

## Назначение

Подтверждение Email или номера телефона.

## Как сюда попасть

После регистрации.

## Что пользователь видит

- Поле ввода кода.
- Таймер повторной отправки.
- Кнопку «Отправить код ещё раз».
- Кнопку «Изменить Email/Телефон».

## Что пользователь может сделать

- Ввести код подтверждения.
- Запросить новый код.
- Вернуться назад.

## Переходы

- Create PIN Screen.
- Registration Screen.

## Особенности

После успешной проверки автоматически начинается настройка безопасности приложения.
