---

## Мета

| Поле | Значение |
|------|----------|
| Фаза | R? |
| Дата | YYYY-MM-DD |
| Трек | T2 Reality |
| Связанная спека (T1) | путь к файлу |
| Статус заметки | draft / confirms / gaps-open |

## As-is (как работает сейчас)

Что реально делает LIVE / код / деплой. Факты, не пожелания.

-

## Confirms (что подтверждает to-be)

Пункты целевой спеки, которые уже совпадают с поведением.

-

## Gaps (что расходится или отсутствует)

| | | |
