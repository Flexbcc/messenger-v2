# Decisions

> **Status:** Draft
> **Last updated:** 2026-07-08

This directory holds **Decision** documents — the stage where the project's
author makes an explicit architectural choice, based on the preceding
Comparison, which is in turn based on Research.

Pipeline position (fixed by the
[Documentation Quality Standard](../00-overview/0008-documentation-standard.md)):

```
Research  →  Comparison  →  Foundation  →  Decision  →  ADR  →  Specification (RFC)  →  Implementation
```

Rules for documents in this directory:

- A Decision is made by the author only. The AI never decides on its own.
- Each Decision references the Comparison document(s) it is based on.
- Once a Decision is made, it is recorded under **Approved** in the decision
  journal ([../00-overview/0007-project-status.md](../00-overview/0007-project-status.md)),
  and a corresponding **ADR** is written in `docs/07-adr/` explaining *why*.

No decisions have been made yet. This directory is intentionally empty of
decision documents pending the Comparison → Decision step.
