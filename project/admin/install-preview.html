Одна команда — полноценная нода

Официальный сайт выдаёт только загрузчик. Секреты создаются на вашем сервере и никогда не отправляются на сайт OUO. Дальше установщик ведёт пользователя через терминал или локальную веб-панель.

curl -fsSL https://ouo.example/install | sudo bash

В реальном релизе загрузчик сначала проверит подписанный manifest и SHA-256 пакета. Этот адрес пока демонстрационный.

Как OUO проверяет установщик перед релизом

Это внутренние автоматические проверки разработчиков, а не действия пользователя после установки. На сервере пользователя выполняются только preflight до запуска и итоговый health-check.

1. Dry-run

Test-runner строит план и подтверждает, что файлы и Docker не изменились.

tests/installer/run --dry-runПройдено
2. Одноразовые контейнеры

Чистые Linux-контейнеры выполнят установку и будут удалены вместе с тестовым окружением.

Следующий этап
3. Чистая локальная VM

Будут проверены firewall, systemd, перезапуск, обновление и удаление setup-token.

После контейнеров
4. Тестовый VPS/Proxmox

Отдельный прогон проверит DNS, HTTPS, регистрацию и внешнюю доступность.

Требует стенд
5. Матрица режимов

Runner проверил общую/свою сеть × Admin/без Admin в изолированных каталогах.

tests/installer/run --matrix4 из 4 пройдено
6. Ошибки и повторный запуск

Проверены отсутствие домена для HTTPS и сохранение ключа при повторной установке.

tests/installer/run --negativeБазовые проверки пройдены
