02

Сеть и Discovery

Discovery используется для регистрации и поиска других нод. Это внутренний адрес между контейнерами.

Несколько независимых DiscoveryD1/D2/D3 · quorum

Нода регистрируется и отправляет heartbeat независимо в каждый указанный Discovery. Критические маршруты, peer-view и federation trust сверяются по нескольким источникам; первый адрес остаётся только совместимым bootstrap-указателем.
