Flex Messenger — клиент для частной сети узлов (Home, Media, Discovery, Gateway). Переписка шифруется на устройстве, медиа хранится у вас или на вашем storage-app, а не у корпорации-посредника.

macOS · Web Android · Windows · iOS канал: beta

Что это и зачем

Это не «ещё один Telegram-клон». Архитектура рассчитана на свою инфраструктуру: вы поднимаете ноды (или подключаетесь к сети оператора), клиент получает маршрутизацию через Gateway и ходит напрямую на Home/Media за данными.

Messenger — приложение для чатов, звонков WebRTC, каталога настроек приватности (~180 параметров), private mode со скрытыми чатами и PIN, pairing новых устройств по QR.

Storage App — настольное личное хранилище: content-addressed blobs, SQLite-метаданные, tray-иконка, Bonjour в LAN, Ed25519 для доверия. Альтернатива S3 для медиа мессенджера.

Сейчас стадия 0.1.0 beta — функционал активно дорабатывается, возможны сбои. Клиенты проверяют обновления через Gateway и предлагают перезагрузку (Web) или скачивание (desktop).

Возможности

E2EE-чаты

Signal Protocol в Dart — работает и в браузере без нативных библиотек.

Звонки

WebRTC audio/video, минимизация звонка, speaker на desktop.

Private Mode

Скрытые чаты в AES-GCM vault, отдельный PIN, decoy PIN.

Настройки

Каталог privacy/contacts/security — persist на Home Node.

Децентрализация

Discovery + Gateway + Home/Media — без единой точки чтения переписки.

Автообновления

Manifest на Gateway: Web — «Перезагрузить», desktop — ссылка на новый билд.

Как устроено

  1. Клиент → Gateway: bootstrap, invite, manifest обновлений
  2. Gateway → Discovery: каталог доверенных нод
  3. Клиент → Home Node: чаты, сообщения, настройки, WS push
  4. Клиент → Media Node: upload/download медиа
  5. Storage App (опционально): ваш blob-store в LAN или на VPS
