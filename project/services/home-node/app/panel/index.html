Добро пожаловать

Home Node — ваша личная точка в сети Messenger. Она хранит ваши данные, связывает устройства и при желании помогает другим участникам.

  • Данные остаются у вас — не на чужом сервере
  • Сеть видна обезличенно: только роли и статус, без адресов
  • Участие в relay/storage — по вашему выбору, можно отключить

Настройка займёт пару минут. Всё можно пропустить — система подберёт разумные значения сама.

О вас

Имя для панели и необязательный вход администратора — только рекомендации, жёстких правил нет.

Отображается в панели, не уходит в сеть.

Рекомендуем не оставлять пустым, если панель доступна из интернета.

Сохраняется локально на ноде. Полноценная авторизация будет позже.

Участие в сети

Без внешних сервисов и ключей — только то, что нода уже умеет. Можно включить позже в панели.

40% для вас · 60% для сети

Чем выше «для вас», тем меньше ресурсов уходит на помощь сети.
