# 0400. Клиент

## Статус
Черновик

## Назначение
Общие требования и архитектура клиентских приложений вне зависимости от
платформы. Client ([[0004_GLOSSARY]]) никогда не является сервером и не
берёт на себя ответственность узлов инфраструктуры.

## Поддерживаемые платформы
Мобильные (iOS, Android), десктоп (Windows, macOS, Linux) и, опционально,
Web — конкретная реализация описана в [0401_FLUTTER.md](0401_FLUTTER.md).
Поддержка конкретной платформы — решение реализации, а не требование
протокола (Replaceable Everything): любой Client, соответствующий
[0200_PROTOCOL.md](0200_PROTOCOL.md), совместим с сетью независимо от
платформы и языка.

## Архитектура клиента
Слои клиента, от интерфейса к сети (Loose Coupling — каждый слой знает
только о соседнем):

```
UI (представление)
  │
Состояние приложения (view state, не путать с Session)
  │
Core (0500) — протокол, крипто, локальная бизнес-логика
  │
Локальное хранилище (зашифрованная БД)  │  Сетевой транспорт
```

UI-слой не обращается к сети или локальному хранилищу напрямую — только
через Core (Single Responsibility).

## Локальное хранилище на клиенте
- Вся локальная база данных Client шифруется целиком (см. [0300_CRYPTO.md](0300_CRYPTO.md) → Шифрование хранимых данных).
- Ключ шифрования локальной БД производится из защищённого хранилища платформы устройства (Keychain/Keystore) и, опционально, пользовательского фактора разблокировки приложения.
- Резервное копирование локальных данных, если поддерживается платформой, выполняется только в зашифрованном виде; ключи расшифровки не передаются вместе с бэкапом через недоверенный канал.

## Офлайн-режим
Каждое пользовательское действие (отправка сообщения, реакция, создание
Conversation) сначала фиксируется в локальной очереди (Queue,
[[0004_GLOSSARY]]) и немедленно отражается в UI, независимо от текущего
состояния сети (Offline First). Синхронизация с сетью происходит
автоматически при восстановлении соединения, без участия пользователя.

## Push-уведомления
Push используется исключительно как сигнал «есть что забрать» — платформа
push-уведомлений (например, APNs/FCM) не получает содержимое Message и не
может его прочитать (Privacy by Default). Получив push, Client
самостоятельно подключается к своей Home Node и забирает накопленные
Packet по защищённому каналу.
