# simulation — симуляция сети мессенджера

Отдельный самостоятельный проект. Моделирует поведение сети из множества нод
(home/relay/storage/discovery) без реального деплоя: регистрация, heartbeat,
резолв UserID→HomeNode, доставка/федерация, relay-fallback, обновления.

Цель — проверять сценарии сети, не поднимая настоящий кластер и не загружая
в контекст весь основной проект.

## Структура
- `src/`        — движок симуляции (узлы, транспорт, часы, метрики).
- `scenarios/`  — YAML/JSON-сценарии (N нод, отказы, версии, нагрузка).

## Идеи сценариев
- Много relay разных версий (0.1.0/0.2.0) как микрохабы — see backend SUMMARY.
- Пропажа выбранного relay при непротухшем heartbeat (retry across relays).
- Массовая регистрация клиентских нод и heartbeat в discovery.
- Раскатка обновлений (NODE_RELEASE_SIGNATURE) по клиентским нодам.

## Связи
- Логика ссылается на спеку `../backend/spec` (0103_NETWORK, 0203_ROUTING, 0900_DEVOPS).
- Не зависит от рантайма backend — можно гонять автономно.
