# Сопряжение (pairing) — нода↔хранилище и телефон↔хранилище

> Unified QR-модель (node-mode / direct-mode, payload v2, маршруты LAN→mDNS→relay):
> [`PAIRING-FLOWS.md`](PAIRING-FLOWS.md).
> Актуальный статус реализации компонентов — раздел
> [Implementation status](PAIRING-FLOWS.md#implementation-status) в том же документе.

## Ключи
- storage-app при первом запуске генерирует пару **Ed25519** (`SK_storage`,
  `PK_storage`), хранит SK в защищённом хранилище ОС (Keychain/DPAPI/libsecret).
- Каждый пир (нода или телефон) имеет свою пару (`SK_peer`, `PK_peer`).
- Сопряжение = взаимная запись публичных ключей в `paired_peers`.

## Node-mode (нода ↔ хранилище)
1. В storage-app: «Добавить ноду» → показывает **код/QR** = `PK_storage` +
   адресные хинты (lan_hint, relay_url).
2. На ноде (или в её админке `../backend/admin`): ввести код → нода отправляет
   `PAIR_REQUEST{ PK_peer, name }`, подписанный `SK_peer`.
3. storage-app показывает запрос → пользователь подтверждает → пишет `PK_peer`
   в `paired_peers`, отвечает `PAIR_OK{ PK_storage }`.
4. Нода сохраняет `PK_storage` в профиль backend `personal_pc`. Готово.

## Direct-mode (телефон ↔ хранилище, без своей ноды)
1. storage-app публикует себя в общую сеть (discovery) под своим `PK_storage`.
2. В телефоне (`../frontend`): «Подключить хранилище» → скан QR / ввод кода.
3. Тот же обмен `PAIR_REQUEST`/`PAIR_OK`, транзит — через relay сети.
4. После пары телефон адресует блобы напрямую в storage-app (PUT/GET, §5 SPEC).

## Подтверждение и защита
- Код сопряжения короткоживущий (TTL, напр. 5 мин) и одноразовый.
- Показ отпечатка ключа (fingerprint) с обеих сторон для сверки (MITM-защита).
- Любой запрос после пары подписан ключом пира; неизвестный ключ → отказ.

## Управление парами
- Список пиров в UI: имя, fingerprint, последняя активность, объём.
- **Revoke**: удалить `PK_peer` из `paired_peers`; опция «удалить его блобы».
- Ротация ключей пира — повторное сопряжение.

## Открытые вопросы
- Нужен ли PIN на самом storage-app при подтверждении.
- Мульти-пир: несколько нод/телефонов на одно хранилище — квоты на пира.
